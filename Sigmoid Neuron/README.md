# Sigmoid Neuron

A single sigmoid neuron implemented from scratch with NumPy, trained with gradient descent on squared error loss.

Unlike the [Perceptron](../Perceptron), which uses a hard step-function threshold, this neuron uses a smooth sigmoid activation, giving continuous outputs between 0 and 1 and allowing gradient-based learning via the derivative of the sigmoid.

## Files

- `SigmoidNeuron.py` — implementation and training on a 2-input logic-style dataset
- `Neuron_Foundations_Lecture.pdf` — lecture notes
